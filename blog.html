Workshop 4: Data Visualization

This week, as an extension of data practice, we shared our observation about the homework — collect and code data that related to our selected topic. Besides, we also learned about how to visualize data that we have already collected.

During the workshop, we shared our current difficulties about data collecting and the measures to improve if we have enough time. We mentioned that the data we had collected may be subjective, because it is hard to put a post into an exact category — they often lie somewhere between categories. We also mentioned that if we have enough, we may compare data from different platforms and different period.

What I learned from this workshop are as follows. First, there are lots of ways to visualize data, such as excel, tableau and some other tools. The charts that we made have to be easy to read, they have to have a title, have to tell the audience where the data comes from. Second, different types of data need to be presented with chart types suited to them. The data sample we collected this time was relatively small, and most of the data were about frequency rather than showing trends over time. We therefore chose bar charts and pie charts to visualise the data.

Perhaps because I had some prior exposure to data visualisation and a little experience with chart-making, I found this session relatively manageable for me. All in all, I consider that with the more workshop that I took, the better I adjust with the pace and the content.
